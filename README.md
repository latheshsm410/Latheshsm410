# Portfolio Website

This is my personal portfolio website created using a single index.html file. The website showcases my introduction, skills, projects, certifications, and contact details. It is simple, responsive, and built using HTML, CSS, and JavaScript inside one file.

## 🌐 Live Portfolio
This site is deployed using GitHub Pages.

## 📌 About This Website
This portfolio includes:
- Introduction section with buttons
- Overview, interests, and goals
- Skills section
- Projects section
- Certifications section
- Contact section
- Responsive design for mobile and desktop

## ✨ Features
- Simple and clean UI
- Fully responsive layout
- Works with a single HTML file
- Download resume button
- Smooth navigation and interactions

## 🚀 How to View
1. Open `index.html` in your browser  
2. No installation or setup required  

## 📤 Deployment (GitHub Pages)
1. Go to **Settings → Pages**  
2. Select **main branch**  
3. Save  
4. Your live website will be published
